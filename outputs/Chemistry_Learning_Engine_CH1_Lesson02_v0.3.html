02 / 从这道题找到规律

怎样知道谁会形成沉淀？

沉淀：反应中生成并从溶液里析出的难溶固体。
难溶：在水中只能溶解很少，并非一点都不溶。
(aq)：物质在水溶液中。
(s)、↓：固态；箭头在这里提示有沉淀生成。

混合后，先列出溶液里的离子，再考虑它们重新组合的产物。本题有：

Ba²⁺Cl⁻＋Na⁺SO₄²⁻
① 重新配对Ba²⁺＋SO₄²⁻ → BaSO₄；Na⁺＋Cl⁻ → NaCl。
② 查溶解性BaSO₄ 难溶；NaCl 易溶。
③ 判断现象在本实验条件下，BaSO₄ 形成白色沉淀；Na⁺、Cl⁻ 留在溶液中。

“白色”只能描述现象，不能单凭颜色确定化学式；判断还要结合加入了哪些离子和产物的溶解性。

高一先掌握这些常见规律

离子类别常见规律本课要认出的例子
Na⁺、K⁺、NH₄⁺；NO₃⁻它们形成的常见盐通常可溶NaCl、Na₂SO₄、KNO₃、NaNO₃ 留在溶液中
Cl⁻多数氯化物可溶；记住 AgCl 难溶Ag⁺＋Cl⁻ → AgCl↓（白色）
SO₄²⁻多数硫酸盐可溶；记住 BaSO₄ 难溶Ba²⁺＋SO₄²⁻ → BaSO₄↓（白色）
CO₃²⁻多数碳酸盐难溶；钠、钾、铵盐是常见例外Ca²⁺＋CO₃²⁻ → CaCO₃↓（白色）
OH⁻多数氢氧化物难溶；NaOH、KOH、Ba(OH)₂ 可溶Cu²⁺＋2OH⁻ → Cu(OH)₂↓（蓝色）

要背下来吗？为什么？

要记“规律＋高频例外”，不用一口气背完整张表。先记钠、钾、铵盐和硝酸盐通常可溶；再记 AgCl、BaSO₄、CaCO₃、Cu(OH)₂ 等常见难溶物。

记它们是为了预测会不会出现沉淀、写离子方程式时决定哪些物质不能拆、以及判断哪些离子能在同一溶液中大量共存。遇到微溶或不熟悉的物质，再查溶解性表。

为什么有些难溶？离子组成晶体的吸引作用与水分子使离子分散的作用共同决定溶解程度。难溶不等于完全不溶；实际是否析出也与溶液中的离子浓度有关。这里按常见课堂实验条件判断。

04 / 拆

选择应写成离子形式的物质

BaCl₂(aq) + Na₂SO₄(aq) → BaSO₄(s) + 2NaCl(aq)

点击应拆分的物质，可以选择多个。“可溶性强电解质”在水中主要以自由离子形式存在，本例中的 BaCl₂、Na₂SO₄ 和 NaCl 水溶液属于此类；难溶的 BaSO₄ 沉淀保留化学式。

提示：本例中的可溶性强电解质写成离子形式；沉淀仍写化学式。
05 / 删

哪些离子在两边都没有变化？

完整离子式：

Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄(s) + 2Na⁺ + 2Cl⁻

点击需要从两边同时删去的旁观离子。
