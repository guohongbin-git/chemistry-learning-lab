## 启动

在终端进入本目录，运行：

```bash
./start.command
```

然后打开 `http://127.0.0.1:8765`。按 `Ctrl+C` 停止服务。服务需要 Node.js；使用个性化导师还需已登录的 `mmx` CLI。课程本身不需要安装 npm 依赖。如果直接打开 `index.html` 的 `file://` 地址，页面会提示本地文件模式；术语库与动态导师需要从上述 HTTP 地址进入。

如果主动使用导师时页面显示“MiniMax CLI 需要重新登录”，请在自己的终端按[官方 CLI 文档](https://platform.minimax.cn/docs/token-plan/minimax-cli)运行 `mmx auth login --api-key <你的密钥>`，不要把密钥写进课程文件或聊天。成功后下一次导师请求会读取新的登录状态，无须重启课程。基础判断和高考训练的固定解析不依赖 CLI 登录。

原有两节情境互动版仍可直接打开：`http://127.0.0.1:8765/Chemistry_Learning_Engine_CH1_v0.5.html`（含“电解质水”情境）和 `http://127.0.0.1:8765/Chemistry_Learning_Engine_CH1_Lesson02_v0.4.html`（含沉淀判断与逐段高考迁移）。它们可独立练习；需要根据自由解释追问时再使用首页的 CLI 导师课程。

可以通过环境变量覆盖模型或端口，例如：

```bash
TUTOR_PROVIDER=agy AGY_MODEL=gemini-3.8-flash-medium PORT=8766 ./start.command
```

使用其他端口时，打开对应的 `http://127.0.0.1:端口`。

默认 `TUTOR_PROVIDER=mmx`，使用 `MiniMax-M2.7-highspeed` 模型，可用 `MMX_MODEL` 覆盖；`MMX_BIN` 可指定另一个 `mmx` 可执行文件。导师不可用时，主动点评或自由追问会显示明确错误，固定解析和下一题仍可正常使用。化学事实与学习路径由本机课程控制。

## 教学机制

1. **唤醒初中知识**：八个单元各有开课前回顾。答错先看解释，再做一道更小的确认题；回顾不计入高一案例成绩。已掌握的学生可选择直接进入课程。
2. **先学后判断**：第一章先看分类、离子反应和氧化还原；第二章依次看钠、氯、物质的量和配液实验。案例理由可选写。
3. **立即反馈**：程序判定化学事实并显示固定解析。学生愿意时再写理由、请求 CLI 导师点评；不用导师也能完成课程。
4. **对比与迁移**：第一章用空气/纯水/盐水、盐/糖/酸、沉淀/无沉淀和氧化还原正反例建立规则。第二章比较 Na/Na⁺、Na₂O/Na₂O₂、Cl₂/Cl⁻、HCl 气体/盐酸，练粒子数与质量换算、标准状况条件和配液误差。答错时可插入对应补救案例。
5. **学生追问**：每题反馈后可自愿向导师提出一个自由问题，或直接继续。
6. **回忆提示**：结束时根据初中回顾和高一案例中的错误给出回看重点，并建议次日主动解释几个新例子。
7. **随时查术语**：右上角打开术语库；每个回顾题和案例下方有相关术语入口。提交后，导师可指出一个值得回看的词条。每个词条都有独立定义；原有 19 个高频概念、第一章新增 23 个概念和第二章新增 26 个概念有“必须背—老师示范—两组正反例—遮住答案快测”。快测全对后安排 1、3、7 天复习，记录只存在当前浏览器。支持中文名、化学式和别名搜索。

## 高考迁移训练

每个单元的五个学习步骤现在各有三道原创判断题，共 120 题。学习页面“真题考法 · 课程自编三题”卡片可以自由切换五步；每题提交后显示判断理由、该题考点与应记规则，再给一道新情境题检验能否举一反三。第一题明确要求记住“混合物由两种或两种以上不同物质组成；纯净物由一种物质组成”，再分别用纯 CO₂、金刚石与石墨的混合物、糖水检验“物质种数”与“元素种数”的区别。三道主练习做完会显示本步的必会知识点和记法。练习结果保存在当前浏览器本地，不调用 CLI 导师，也不阻挡主线学习。`step-practice.js` 与 `step-practice-ch2.js` 保存主练习、解析与原卷考法依据，`step-transfer.js` 与 `step-transfer-ch2.js` 为 120 题分别保存考点名称和独立迁移题；遇到高考没有直接考查的生活场景，页面会说明是邻近考法的延伸。

首页分别设有第一、二章的四选一训练入口；完成对应基础单元后也可进入本节训练。每题先读情境和条件、选一项，理由可选写。提交后立即显示固定正确答案、四个选项各自的判断依据、完整推理、一个“换条件再想”的问题；需要个性化反馈时再点“请导师点评我的理由”。模型不能改变正确答案或解析；导师暂不可用时也能完成整套训练。题目及每个选项的解释在 `exam-bank.js`，附人民教育出版社教材资料、教育部考试大纲或浙江省教育考试院 2022—2025 年评析与命题思路链接，均清楚标为“考法参考、题目自编”。

第二课的“怎样判断沉淀”折叠卡会在课程开始时展开：先列离子、重新配对、查溶解性，再用三种沉淀与一个无沉淀反例练习。新版互动课程还加入酸性条件下的离子共存判断，以及各环节高考思路题。建议记常见规律和高频例外；遇到微溶或少见物质查表。难溶不是绝对不溶，实际析出还与浓度等条件有关。

术语库运行时共有 142 条，覆盖第一、二章当前八单元的核心概念、常见物质与离子。基础词条 93 条保存在 `glossary.json`；第一章新增 23 条保存在 `chapter1-content.js`，第二章新增 26 条保存在 `chapter2-content.js`。没有 CLI 导师响应时仍可查阅；此数量不代表整册教材所有术语。

电解质词条现在同时展示 NaCl、HCl、NaOH、醋酸等正例，以及蔗糖、铜、盐酸、CO₂ 等不同原因的反例。学生要分别判断“是否为化合物”“换成水溶液或熔融体后是否有可移动离子”，不能用眼前样品是否点亮灯泡代替物质分类。其他已有词条仍保留原有例子与易错提醒；后续新增章节按 [`TEACHING_DESIGN.md`](TEACHING_DESIGN.md) 的正反例与快测规则扩充。

第一课现在明确区分常见食糖的主要成分蔗糖（C₁₂H₂₂O₁₁）、葡萄糖（C₆H₁₂O₆）和果糖（C₆H₁₂O₆）。这三种糖均由碳、氢、氧组成；葡萄糖和果糖分子式相同、结构不同。课程用蔗糖与葡萄糖水溶液的判断题说明：糖溶于水后主要仍是中性分子；含糖饮料若含盐，导电与盐提供的离子有关。生活情境版在“场边补给站”也有对应的分子式表和配料表练习。

关于水：理想纯水会极微弱自电离，25 ℃理论电导率约 0.055 μS/cm。普通课堂小灯泡通常不明显发亮，但这不等于绝对不导电；自来水与蒸馏水又是不同的实际样品。高一阶段先学定性判断，暂不要求水的离子积计算。科学依据和代表性历年高考题与课程改编的对应关系见 [`TEACHING_DESIGN.md`](TEACHING_DESIGN.md)。

原有初中回顾写在 `prerequisites.json`，新增第一章回顾写在 `chapter1-content.js`，第二章回顾写在 `chapter2-content.js`；新增第二章案例也在 `chapter2-content.js`。CLI 导师的输出不能改写化学事实或术语定义。模型不可用时仍能查看课程固定解析。

## 运行边界

- 服务只监听 `127.0.0.1`，课程会话暂存在本机服务内存中，服务重启后需重新开始。
- 初中知识回顾、基础案例判断和高考题评分由本机课程规则处理，不调用模型。只有学生主动请求导师点评或追问时才调用已配置的 MiniMax 或 `agy`，可能使用联网模型和相应额度。本程序不把学生回答另存为文件。
- MiniMax 仅调用 `mmx text chat`，不向模型开放工具；可选的 `agy` 路径使用 `--mode plan`、`--sandbox` 和 `--disable-slash-commands`。两种 CLI 都在空的 `work/agy_tutor_runtime/` 中运行。
- Agentic 路径已覆盖第一章三节及第二章四个单元的基础教学与高考考法迁移。第二节原有固定“方程式编译器”仍保留为可选操作练习。更深的沉淀平衡与电化学定量计算留到后续章节。

## 快速自检

服务启动后，可在另一个终端运行：

```bash
curl http://127.0.0.1:8765/api/health
```

应返回 `status: ready`、`agent`、当前模型名和 `tutorStatus`。`ready` 只表示本机课程服务已启动；`tutorStatus: not_tested` 表示还未验证 CLI 登录，`auth_required` 表示 MiniMax 鉴权失败。

完整路径回归检查：在项目根目录运行 `node work/lesson02-dom-test/test-ch1-completion.cjs` 和 `node work/lesson02-dom-test/test-ch1-exam.cjs`；前者验证第一章四单元的 81 个核心案例，后者遍历第一、二章共 22 道高考迁移题的固定答案、逐项解析、来源与界面。

第二章可运行 `node work/lesson02-dom-test/test-ch2-completion.cjs`，验证四单元的 80 个核心案例、术语、初中回顾和界面。

本次试卷补漏可运行 `node work/lesson02-dom-test/test-september-exam-review.cjs`，检查课程入口、21 道题的交互、关键方程式和新增术语。

步级三题可运行 `node work/lesson02-dom-test/test-step-practice.cjs`，检查 40 步 120 道主练习、120 道迁移题、考点、定义、原卷链接与三题后的归纳显示。
