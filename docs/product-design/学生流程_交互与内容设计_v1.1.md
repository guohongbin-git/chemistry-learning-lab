上述机制组合成我们自己的体验：**教材关系图定位置 → 分步讲解与样品对照 → 示范推理 → 记忆卡 → 可选三题及具体补学 → 回到课程**。采用通用交互机制，不复制这些产品的视觉素材、课程正文和商标。

### 0.1 可验证的参考结果

本轮原型须体现 OpenStax 启发的“完整讲义与关系图”、Brilliant 启发的“当前一步与即时样品对照”、Quizlet 启发的“遮挡回忆与收藏”、Khan Academy 启发的“按能力给反馈和下一步”。PhET 的完整实验联动列入 X 规格，分类课只展示条件切换原则，不宣称已经制作新的化学模拟。

后续学生观察重点是：能否快速找到当前讲解、能否解释两组反例、查词后能否回到原处、是否知道读完与会做的区别、跳过练习是否顺畅。设计依据不能只写产品名称，每次采用都要能指到页面动作与验收任务。

## 1. 本次纠正的设计问题

v1.0 有学习旅程和教学原则，但不足以决定每一屏怎么制作。当前 `product-v1/app.js` 的首页状态和进度主要依赖练习首答，`openUnit` 重置当前交互状态；`renderUnit` 将大量内容堆在一页；`currentPractice` 将主练习和迁移题串成完成序列。分类已有原图带读，其他单元仍偏短解释加正反例列表。学生可能读完却看见“未开始”，或离开活动后找不到原来的位置。

本设计把三件事落实为可验收对象：**进入后看到什么、操作后发生什么、每一步具体教什么**。完成代码测试是开发者的职责；用户说“教学”或“继续优化”时，应继续改善教学产品，不自动把用户当学生连续出题。

## 2. 产品默认如何迎接学生

### 2.1 信息结构

主导航仅保留「学课程」「练与复习」「学习记录」。全局「查概念」通过搜索进入；实验同时存在于相关课程与实验索引；试卷复盘在「练与复习」内。导师是随任务打开的帮助面板。所有入口名称描述学生能做的事。

首页的主体是一个具体学习建议，例如「继续：为什么盐酸是混合物」，按钮是「回到上次位置」。首次无记录时展示「从物质分类开始」，允许先浏览目录。教材/年级选择可稍后补充；不在开始学习前要求考试地区、诊断测验和账号全部完成。

课程目录展示「章 → 教材节 → 本产品短课」，短课是可暂停的教学片段，不假装等同于教材节。每节有一张关系总图和覆盖清单。首批四个主题是样板，不据此标记“第一章全部知识完成”；胶体、分类与转化、氧化物等须在对应覆盖清单单独列出。

### 2.2 三种入口的主次与行为

| 入口 | 默认落点 | 页面主要动作 | 学生能立即改选 |
| --- | --- | --- | --- |
| 我要学这节 | 当前短课的讲解步骤；首次从情境/总图进入 | 继续讲解 | 看完整讲义、直接练习、选其他小节 |
| 我只想查一个词 | 对应概念卡，不进入课程第一屏 | 返回原处 | 看对比例子、打开相关短课 |
| 我想练一下 | 范围和练习目的选择，再显示题目 | 开始练习 | 先看讲解、缩小范围 |

默认不计时、不考试、不弹出导师追问。只有学生主动选择「独立检验」才进入无帮助状态，入口明确告知可以随时退出查看讲解。自主阅读模式一次展开全部讲解，讲解的顺序和事实与分步模式相同。

| H / 学习首页 | 一个继续入口、推荐理由、当前教材章节、三个自由入口 | 继续学习 → 精确回到步骤 | 改学其他节；查概念 | 无记录显示起点；保存失败持续提示“本次仅临时记录” |

### 3.1 学习页布局

桌面：左侧短课目录，中间教学内容，右侧面板按需打开。侧栏关闭时正文有合理最大宽度，避免整屏长行。顶部有「回课程」「当前小节」「查概念」，底部显示上一步、下一步及当前步数。正文主标题写学习问题，如“水里有两种元素，为什么仍是纯净物？”

手机：单栏，目录按钮展开可关闭列表；术语使用可关闭面板。底部操作不遮最后一段；公式在独立区域必要时横向滑动，页面本身不横向溢出。原图默认完整显示，点击放大后可返回，禁止为适配裁掉关系分支。原图加载失败时仍可读文字关系。

视觉层次：先问题和原图，再短段讲解，再实例，最后可展开深入内容；“要记住”用统一但不刺眼的卡片。历史、生活故事与考试分析不同时抢占首屏。字色与图标同时表达正误；键盘焦点可见；动画默认不自动播放。

### 3.2 返回与保存契约

保存位置为 `教材/短课/步骤/展开项/活动条件/未提交草稿`。概念、模拟和补学均带返回锚点。学生从某题打开 aq 卡，关闭后应回到那道题，保留选项；从该卡进入短补学，结束后明确出现“返回第 3 题”。浏览器后退优先回到上个页面/步骤。

阅读进度只表示到达/看过的位置。练习单列首次回答、帮助、重做与跳过。用户主动点“本节读完了”可标阅读完成，但不自动标独立掌握。未提交离开时保存草稿，不自动判错。

## 4. 一节课的教学过程与系统行为

默认推荐顺序：**看到一个问题 → 回顾必要基础 → 看原图建立位置 → 定义与对照 → 教师示范怎样想 → 提炼记忆 → 可选三题 → 小结与返回**。这些是可自由跳转的学习步骤，不是锁住学生的关卡。

| 学生动作或情况 | 系统实际回应 | 留下什么记录 |
| --- | --- | --- |
| 不会初中概念 | 展开针对该词的短说明与一个实例；显示“回到刚才” | 看过补学内容 |
| 看了讲解但不想答题 | 允许直接看小结或下一课 | 阅读状态，不生成答题证据 |
| 首答正确 | 先给结论与依据；对照关键条件；可选解释 | 当前题首次结果；不能证明整个主题掌握 |
| 首答错误 | 标出题目中决定答案的条件；给最小对照例 | 错误结果与候选缺口；学生可更正归因 |
| 选择“还不明白” | 换一个表示方式：成分清单、原图分支或逐步例题 | 辅助阅读，不强行增加题量 |
| 直接看答案 | 立即显示答案和推理；允许继续 | 看过解析；后续同题结果为解析后练习 |
| 请求导师 | 在同一面板选择“直接讲”“提示”“换例子”；返回当前任务 | 显示成功后标记收到帮助，不以点击按钮推断 |
| 导师超时/失败 | 固定讲解仍可读，保留问题并允许重试 | 失败事件，不能记为已收到帮助 |
| 推荐不合适 | 可以“我只是看错了”“稍后再说”“换一项” | 原作答保留，推荐意图更新 |
| 在独立检验查答案 | 明确退出检验后立即给讲解 | 本次转辅助；不悄悄保留独立标签 |

## 5. 内容不是标题列表：每一步必须交付什么

一份可实施的课稿必须逐步给出：**屏幕标题、学生可见正文、素材及所指区域、交互动作、反馈全文、必记句、可选深入、下一步与返回点**。不能只填“这里放动画”“解释电解质”“加入三题”。

每个知识点的教学资产包含：先修短解释；规范定义与关键词；至少两组正反例；一段完整示范推理；带边界的记忆方法；三道不同角色的题及反馈；一种真正改变条件的迁移；来源状态。术语卡与课程引用同一条核心定义，避免不同页面说法矛盾。

内容展开分四层：首层一句话先让学生知道是什么；第二层解释依据并举例；第三层处理易错边界；第四层放历史、原理深入或生活应用。每层可直接打开。词条第一次出现就可查，尤其 aq、酸根、自由移动、熔融、难溶和化合价。

### 5.1 首章短课蓝图（制作顺序提案，教材页码待核定）

| 短课 | 从什么问题进入 | 必须讲清的正文逻辑 | 最有用的交互 | 三题分别练什么 |
| --- | --- | --- | --- | --- |
| A1 纯净物与混合物 | 同样透明的纯水、盐水有什么不同 | 组成物质种类；物质/元素不同层次；溶液包含溶剂 | 原分类树带读；展开样品成分清单 | 定义、O₂/O₃ 反例、HCl(g)/HCl(aq) 标签迁移 |
| A2 单质与化合物 | 纯水和纯氧都纯，为什么还要分类 | 先确定纯净物，再数元素；不能用“纯”代表单质 | 原图定位第二层，对照 H₂O/O₂ | 判据、误用混合物、陌生化学式 |
| A3 酸碱盐与氧化物 | NaHCO₃ 有 H，为何不是酸 | 分类对象→电离/组成判据→正反例；盐含铵盐；氧化物的元素条件 | 酸/酸根/盐对照卡，名称可查 | 定义条件、酸式盐/醇反例、给信息再分类 |
| A4 分类与转化 | 同类物质一定发生同样反应吗 | 类别有助预测但要核实具体物质和条件 | 保留原转化图，点击一条箭头看成立条件与例外 | 合理预测、CaO/CuO 对照、路线判断 |
| A5 分散系与胶体 | 为什么光路有时可见 | 按分散质粒子大小分类；光散射证据；制备条件 | 实验现象配粒子示意，切换可见光路和文字说明 | 分类依据、颜色不能作唯一判断、实验信息迁移 |
| B1 导电与电解质 | 食盐晶体有离子，为何灯不亮 | 粒子带电与能自由移动是两个条件；类别对象是化合物 | 晶体/溶液/熔融对照，铜的载流粒子独列 | 导电条件、铜/盐酸类别、改变状态 |
| B2 水、糖与电解质饮料 | 饮料含糖，导电来自糖吗 | 纯水弱导电；糖不等于一种固定物质；蔗糖分子与盐离子 | 成分表→溶质→粒子；保留定义返回口 | 溶解/电离、仪器灵敏度、给定标签迁移 |
| B3 溶解性与沉淀 | 两杯无色溶液为什么有白色固体 | 先教溶解性事实和记忆范围，再组合离子判断 | 查溶解表→混合→观察固体及旁观离子 | 常见沉淀、全可溶反例、题给陌生溶解信息 |
| B4 离子方程式 | 为什么方程式里少了 Na⁺ 和 Cl⁻ | 写→按状态拆→删旁观离子→查守恒及条件 | 分步显示每次删改及原因，可回看原式 | 哪些不拆、为什么删、换反应核对守恒 |
| C1 氧化还原判断 | 没有氧元素也有氧化还原吗 | 化合价变化是判断线索；电子转移解释本质 | 原图配反应前后价态对应 | 判断、沉淀反例、陌生反应 |
| C2 氧化剂与还原剂 | 失电子的一方为什么叫还原剂 | 同一物质的价态变化、得失电子、被氧化/还原、试剂角色对应 | 点击一种反应物贯穿四种表达 | 对应关系、主客体混淆、换反应角色 |
| C3 电子守恒 | 两边得失电子为什么要相等 | 先找变化与每个原子，再考虑个数和总电子数 | 分步配平并核对原子、电荷 | 电子数、系数误区、计量迁移 |

## 6. 完整逐屏示范：先数物质，再看元素

本短课只教纯净物/混合物的判据及与元素种类的区别。酸碱盐是后续短课，不在同一屏塞入整个分类系统。所有步骤均可跳转、回看。

### L0 情境：看起来一样，就属于同一类吗？

显示两个文字标签「纯水：只含 H₂O 的样品」「食盐水：氯化钠溶于水」。正文：“两杯都可能澄清透明，但外观不能告诉我们有几种物质。分类要先看整份样品的组成。”按钮「沿原图看一看」。次入口「物质与元素，先回顾一下」，展开 H₂O 是一种物质、由氢氧两种元素组成的对照；无需回答检查题。

### L1 原图带读：先看第一处分叉

显示现有原课件 `classification-tree.png` 完整图；下方两个可切换的说明按钮「第一层：数物质」「第二层：看元素」。第一层正文：“整份样品只有一种物质，是纯净物；有两种或两种以上物质，是混合物。”第二层正文：“确定为纯净物以后，才按组成元素种类分单质、化合物。纯 H₂O 是化合物，仍是纯净物。”图下提供完整文字关系，点击原图可放大。

### L2 对照：为什么不能只数元素？

同时呈现四行样品对照，可点击成分展开原因。

| 样品条件 | 组成物质 | 元素 | 结论及理由 |
| --- | --- | --- | --- |
| 纯 H₂O | H₂O 一种 | H、O 两种 | 纯净物；只含一种物质 |
| 纯 O₂ | O₂ 一种 | O 一种 | 纯净物；一种元素形成的单质 |
| O₂ 与 O₃ 混合 | 两种物质 | O 一种 | 混合物；同一种元素可形成不同物质 |
| 食盐水 | NaCl 与 H₂O | Na、Cl、H、O | 混合物；水也计入组成 |

O₃ 可查“臭氧，是与 O₂ 不同的氧单质”。说明：“化学式中的元素字母种数不能替代物质种类数。这里先看样品说明；不能将数溶液里离子种类作为分类方法。”

### L3 教师示范：盐酸的标签只有 HCl，为什么是混合物？

完整推理默认可逐步展开，也能直接看全部：

1. 读对象：题目说的是“盐酸这份样品”。
2. 读标记：HCl(aq) 中 aq 表示水溶液，不是某种元素。
3. 列组成：盐酸是氯化氢的水溶液，水也在样品里。
4. 用定义：盐酸属于混合物；题目明确为纯 HCl 气体时，属于纯净物。

小结句：“化学式和试剂名称可能指向不同对象，先读清整瓶样品。”旁注：“纯 H₂SO₄ 与稀硫酸也要区分；单写硫酸时读上下文，浓不等于无水。”aq 卡关闭回到当前步骤。

### L4 记忆：这两句需要记住

卡片正文：“纯净物由一种物质组成。混合物由两种或两种以上物质组成。”关键词强调“物质”，下方写“先数物质，再看元素”。记到能说出判据、给一个正例和一个反例；无需背所有解析。按钮「遮住，试着回想」只是自查，不打分；「显示答案」随时可用。可收藏后继续讲解/练习，不强制背诵提交。

### Q1 辨认定义（原创）

题干：“只含 H₂O 的样品含 H、O 两种元素，所以是混合物。”选项：正确 / 不正确。答案：不正确。

反馈固定展示：“本题考物质分类的判据。要记住混合物是两种或两种以上**物质**组成；H₂O 中元素有两种，但题设物质只有一种。”错选时增加：“你可能把元素种类当成物质种类。可回看四行对照。”变式方向：“换成只含 CO₂ 的样品，判据是否改变？”

### Q2 辨析反例（原创）

题干：“O₂ 与 O₃ 混合，只含氧元素，因此是纯净物。”答案：不正确。

反馈：“本题考同种元素与同种物质的区别。O₂ 与 O₃ 是不同的氧单质；共存时有两种物质，所以是混合物。要理解‘一种元素’不能推出‘一种物质’。”变式方向：已知金刚石和石墨是两种不同的碳单质，判断混合样品。学生不认识它们时题面必须给信息。

### Q3 标签迁移（原创）

题干：“甲为纯 HCl(g)，乙为盐酸 HCl(aq)。哪份是混合物？”选项：仅甲 / 仅乙 / 都是。答案：仅乙。

反馈：“本题考样品对象与状态标记。g 表示气态，aq 表示水溶液；题设甲是纯物质，乙包含溶剂水。要记住盐酸是氯化氢水溶液。”变式方向：甲纯 H₂SO₄、乙稀硫酸。条件改变：若题目改成“气态混合物中含 HCl”，g 本身不能证明纯净。

每题均能提示、看解析、跳过。正确反馈也有原理，不只说“答对了”。三题后可自愿写一句分类理由，对照要点“说明样品含几种物质”“没有用元素种类替代”；文字不自动判分。

### S 本次小结

三张并列但不同含义的状态：“本次浏览：原图/对照/示范”“本次练习：已提交几题，其中哪些看过帮助”“以后再验证：还没有间隔后的表现”。无作答时明确未练习；答对三题也不写永久掌握。展示可保存的必记句，推荐下一短课“纯净物中的单质和化合物”，同时提供复看和退出。复习日期由学生确认，允许取消。

## 7. 另外三条主旅程的具体分支

### 7.1 查 aq，再返回题目

点击题中 aq → K 首屏“一句话：aq 表示该物质在水溶液中的状态” → 正例 HCl(aq)、NaCl(aq)，对照 HCl(g)、NaCl(s) → 可展开“为什么盐酸是混合物” → 关闭回原题且保持已选选项。查词不自动启动课程，不发送导师请求；检验模式先明确转为辅助练习。

### 7.2 从一张试卷补一个缺口

上传/选题 → 看原图和识别文本并确认 → 核对本人答案和参考答案依据 → 显示“这一题需用哪些知识” → 学生选择“符号没懂 / 规则忘了 / 方法没想到 / 看错题 / 暂不确定” → 推荐一个具体片段，如“2 分钟看 HCl 与盐酸对照”（时长为制作估计） → 看完可做一题改变条件的练习 → 返回试卷原题位置。识别不清、答案无依据时保留“待核对”，不能用它更新学习状态。

### 7.3 考前复习

选择范围与可用时间 → 展示可修改的三项以内建议，每项写原因及预计用时 → 开始短回忆 → 按需看规则 → 做新题 → 小结已覆盖/未覆盖。超时不自动交卷；做不完可暂停。默认优先最近明确缺口，学生可选择按目录复习。不得把一次表现换算为高考分数。

## 8. Agent 在学生流程中的位置

系统在完成一次活动后更新“建议下一步”，同时给理由和替代路线；不强制切换页面。固定定义、图片和解析可直接访问。学生点击导师才调用模型，发送当前任务所需上下文；导师可说明“这个问题需要补充条件”，不能擅自修正标准答案或宣布学生掌握。

导师三种明确按钮：「直接讲清楚」「给一点提示」「换个例子」。直接讲解不能被连续反问拦住。回复末尾最多建议一个动作，如“回到原图比较两层分类”，动作带返回点。额外追问、生活展开与历史内容可关；所有建议能拒绝。后台可以先做内容检索与推荐计算，学生无需理解 agent 术语。
