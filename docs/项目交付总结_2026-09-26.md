# 化学学习产品阶段总结 · 2026-09-26

## 产品目标

面向高中生，帮助学生从基础概念、教材关系图和正反例出发，理解化学现象，再将知识迁移到考试情境。当前优先服务北京考生，导师和练习可自主选择。

## 已实现

- 新版第一章按三节教材主题拆为 12 节短课，包含初中回顾、原课件图或文字关系、正反例、分步示范和记忆卡。
- 36 道原创主练习、12 道复习题、26 个术语；逐题显示考点、判断依据、易错原因与条件迁移。
- 北京真题对应：17 道已核对题号的 2023、2025 年北京卷题目，标明直接或相关联系，提供原卷转载链接、考点、记忆方法和迁移追问。这些是考点索引，不是可作答真题题库。
- 自由跳步、完整讲义、返回上次位置、可选 AI 导师、导电与沉淀粒子模型。
- 多个本机学习档案、复习安排、试卷图片和文字复盘、内容自查页面。
- 原第一、二章课程及早期原型保留，旧综合训练尚含其他地区考法参考。
- 已形成产品整体设计、逐屏交互设计、第一章接入计划和实施进度文档。

## 启动与验证

需要 Node.js。在仓库根目录运行：

```bash
cd outputs/chemistry-agentic-v0.1
./start.command
```

打开 `http://127.0.0.1:8765/product-v1/`。基础课程无需模型登录；主动使用导师时需要本机已配置的 MiniMax 或 agy CLI。

在仓库根目录运行 `node work/test-short-course.cjs` 检查短课数据、答案索引、术语、原图及北京卷对应。提交前另对全部项目 JavaScript 执行语法检查，并检查本地页面的 HTTP GET 响应。

## 当前边界与后续工作

- 当前为本机原型，没有账号、跨设备同步或教师审核发布系统。
- 尚需独立教师审校、教材地区要求核验及学生学习效果验证。
- 部分基础定义仅找到相关北京题，不能声称每个部分已经配齐三道直接真题。
- 后续优先补充北京各区一模、二模与高考真题，核对年份、区县、题号和答案后再接入；继续迁移第二章到新版教学流程。
- 课件原图来自用户资源包，真题链接来自转载站；仓库已按用户要求公开；课件与真题仍保留原有来源说明，不代表取得第三方材料的再授权。
